# Data

This repository includes the official train and test CSV files from the **BANKING77** dataset, plus the 77-category label list.

- Source repository: [PolyAI-LDN/task-specific-datasets](https://github.com/PolyAI-LDN/task-specific-datasets/tree/master/banking_data)
- Paper: [BANKING77: Intent Detection on Online Banking Queries](https://aclanthology.org/2020.nlp4convai-1.5/)
- Dataset license: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

Files:

- `raw/train.csv` — 10,003 labelled training utterances
- `raw/test.csv` — 3,080 labelled test utterances
- `raw/categories.json` — 77 intent names
